# 使用 Fishbook

## 从一篇论文开始

拖入 PDF，或按 ⌘O 批量导入。重复文件会被识别，失败项会单独列出。

默认左侧原文、右侧中文材料。按 ⇧⌘O 添加本地 Markdown、TXT 或 Fishbook 讲解 JSON；确认对应论文、材料类型和名称。更新同一份材料时会保留旧稿，已有记录仍指向创建时的版本。

左右两边各自滚动。材料中的 `[查看第 3 页](zhiye://page/3)` 会跳到 PDF 第 3 页，前后导航可以返回。这里使用 PDF 页序，可能与论文印刷页码不同。

## 标记与批注

PDF 顶部的笔尖按钮展开标记工具。先选择文字，再选择高亮、下划线或删除线；圆形色块切换黄、绿、蓝、粉、紫、橙。右键选区也能添加标记。

“写批注”与“留下疑问”支持有选区或仅记录当前页。批注列表可以搜索摘录和正文、按类型筛选、定位原文、修改样式、编辑或删除。⌘Z 撤销，⇧⌘Z 重做。

标记平时保存在资料库中。“导出带批注的 PDF”生成标准 PDF 批注副本；原文件不会被改写。原 PDF 自带的批注会单独列出，导出时也会保留。

## 导航和沉浸阅读

PDF 左上角目录按钮包含大纲、缩略图和书签。大纲支持搜索及折叠；书签可以重命名，没有大纲的 PDF 也可以用书签导航。

⇧⌘F 进入沉浸模式，Esc 返回此前布局。搜索或弹窗打开时先关闭它们。标记、批注和导出在沉浸模式中同样可用。PDF 配色独立于界面浅深色；查看需要准确辨色的图表时可切回“原色”。

| --- | --- |
| 搜索当前阅读区 | ⌘F |
| 深度理解 / 全文翻译 / 我的记录 | ⌘1 / ⌘2 / ⌘3 |
| 写疑问 / 写笔记 / 高亮选区 | ⇧⌘Q / ⇧⌘N / ⇧⌘H |
| 保存正在编辑的记录 | ⌘Return |
| 沉浸阅读 | ⇧⌘F |

| 对照 / 只看原文 / 只看中文 | ⌥⌘0 / ⌥⌘1 / ⌥⌘2 |

## 准备学习材料

Markdown 支持标题、段落、列表、表格、代码、本地图像和公式。图像放在文档旁，用相对路径引用，例如 `![图示](assets/figure.png)`；导入时会复制本地资源，网络图像不会自动下载。公式由随应用提供的 KaTeX 离线渲染。

一份简短的讲解可以依次回答：论文解决什么问题、方法如何工作、有哪些证据、什么情况下不适用。译稿可以用“原文第 N 页”组织段落并加入页码链接。导入不会替你翻译或校核正文。

## 保存与备份

正式记录保存前，输入可保留为草稿。右键论文可加入待读、归档或移出；移出后可从“最近移出”恢复，文件和记录仍保留。

在资料库设置中查看保存位置、创建备份或恢复已有备份。恢复前会显示校验结果，并保留恢复前的资料副本。默认资料目录为 `~/Library/Application Support/Fishbook/`，不要在应用运行时手动修改其中的 JSON 文件。

“我的记录”可以按当前论文、待解疑问、全部记录或选择的记录导出 Markdown。“自己讲一遍”用于写下问题、机制、证据和仍说不清的地方，软件不会自动判分。
